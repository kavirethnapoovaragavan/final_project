# 🧠 Customer Lifetime Value Prediction Model  

## 📌 Overview  
This project predicts **Customer Lifetime Value (LTV)** using the **Online Retail Dataset from Kaggle**.  
It helps identify high-value customers, improve targeted marketing strategies, and optimize revenue.  
Python was used for data analysis and modeling, and Power BI for visualization.

---

## 🎯 Objective  
To analyze customer purchasing patterns and predict their lifetime value, helping businesses focus on customers who bring the most long-term profit.

---

## 🛠️ Tools & Technologies  
- **Python:** Pandas, NumPy, Scikit-learn, Matplotlib  
- **Power BI:** Interactive dashboards  
- **Excel:** Initial data exploration  
- **Dataset:** Online Retail dataset (Kaggle)

---

## ⚙️ Steps Involved  
1. **Data Import & Cleaning:**  
   - Loaded the Online Retail dataset into Python  
   - Removed duplicates and null values  

2. **Feature Engineering:**  
   - Created key features: Frequency, Recency, and Average Order Value (AOV)  
   - Aggregated data by unique customer IDs  

3. **Model Building:**  
   - Used **Random Forest Regressor** to predict customer LTV  
   - Evaluated model performance using **MAE** and **RMSE**  

4. **Visualization (Power BI):**  
   - Built a dashboard with segmentation and trend visuals  
   - Highlighted top-value customer groups and seasonal behavior  

---

## 📊 Power BI Dashboard Summary  
**Visuals Included:**  
- Customer Segmentation by LTV (Bar Chart)  
- Recency vs Frequency (Scatter Plot)  
- Average Order Value by Region (Map/Column Chart)  
- Monthly Purchase Trends (Line Chart)  
- KPI Cards: Total Customers, Avg LTV, AOV, Retention Rate  

**Insights:**  
- Top 20% of customers contribute nearly 60% of total revenue.  
- Frequent, recent buyers show the highest predicted LTV.  
- Certain regions show higher AOV, guiding marketing efforts.  
## ✅ Conclusion  
The project provides a data-driven understanding of customer behavior, enabling businesses to retain and engage valuable customers more effectively through personalized marketing and efficient resource allocation.
